# 캐치업코리아 업무 개선 프로젝트

## 개요
캐치업코리아 법인의 업무를 분석하고, 체계적이고 IT의 잇점을 살리는 업무 워크플로우로 개선하기 위한 프로젝트.

## 현재 파악된 상황
- 캐치업코리아는 cafe24 기반의 쇼핑몰을 운영하고 있으며, 모든 상품이 이곳에 등록되어 있는 것으로 보임.
- 이곳에서 판매된 상품들을 관리하는 업무는, 현재까지 별도의 엑셀 파일을 이용한 수기 방식으로 처리되어 온 것으로 파악됨.

## 목표
- 현행 업무 흐름을 분석하여 비효율 지점과 개선 가능한 영역을 도출.
- 분석 결과를 바탕으로 체계적이고 자동화 가능한 IT 기반 업무 워크플로우를 설계·정립.

## 진행 상황
초기 분석 단계. 추가로 파악되는 업무 영역과 산출물은 이 문서에 점진적으로 갱신 예정.
