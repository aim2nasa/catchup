# Cafe24 조회값 상태 보존 정책

## 목적

Cafe24에서 읽어오는 값, 해당 기간 판매가 없는 값, 값의 존재 기준을 확인할 수 없는 상태를 화면, 계산, Excel 다운로드 전 과정에서 명확히 구분한다.

이 정책의 최상위 원칙은 다음과 같다.

- `0`은 Cafe24에서 실제로 조회한 값이 0이거나, 기준표에서 존재가 확인된 상품/옵션이 해당 기간 Cafe24 판매 응답에 없을 때 사용한다.
- 상품/옵션 존재 자체를 확인할 수 없거나 API 실패/응답 중단 등으로 값을 신뢰할 수 없는 상태를 `0`으로 대체하지 않는다.
- 기준표나 로컬 정의로 보강한 값은 Cafe24 조회값처럼 보이면 안 된다.
- 화면과 Excel 다운로드에서 값의 의미와 상태가 동일하게 유지되어야 한다.
- 확인불가 값이 포함된 계산은 사용자가 전체 합계로 오해하지 않게 표시해야 한다.

## 적용 범위

이 정책은 특정 셀 하나가 아니라 Cafe24 조회 결과를 사용하는 모든 값에 적용한다.

- 상품명
- 옵션명
- 상품코드/옵션코드 매칭 결과
- 단가
- 직접판매 수량
- U/L 매핑 수량
- 총판매
- 매출
- 소계
- 전체 합계
- Excel 다운로드 값
- 수식의 입력값과 결과값

## 값 상태 모델

모든 조회 기반 셀은 값만 가지지 않고 상태와 출처를 함께 가진다.

```ts
type CellValue<T> = {
  value: T | null
  status: 'loaded' | 'missing' | 'fallback' | 'partial' | 'calculated'
  source: 'cafe24' | 'set-design' | 'local-rule' | 'calculated'
  note?: string
}
```

상태 의미:

| 상태 | 의미 | 예 |
|---|---|---|
| `loaded` | Cafe24에서 실제 조회한 값 | 직접판매 `0`, 직접판매 `28`, Cafe24 상품명 |
| `missing` | 상품/옵션 존재 기준 또는 필수 값을 확인할 수 없음 | 기준표에 없는 상품/옵션, API 실패, 필수 필드 없음 |
| `fallback` | 기준표/로컬 정의로 보강한 표시값 | `세트할인 구조설계` 기준 상품명/옵션명/단가 |
| `partial` | 일부 입력값이 확인불가인 계산 결과 | 확인불가 항목을 제외한 소계/합계 |
| `calculated` | 조회된 입력값만으로 계산된 값 | 매출, 총판매, 소계 |

출처 의미:

| 출처 | 의미 |
|---|---|
| `cafe24` | Cafe24 API 조회값 |
| `set-design` | `상품출고&순이익(2026).xlsx`의 `세트할인 구조설계` 기준값 |
| `local-rule` | 코드에 고정된 업무 규칙 또는 매핑 규칙 |
| `calculated` | 조회값/기준값/규칙으로 계산한 결과 |

## 표시 원칙

### 숫자 0

`0`은 아래 두 경우에 표시한다.

1. Cafe24 응답에서 실제 수량 0을 받은 경우
2. 기준표에서 상품/옵션 존재가 확인되었고, 해당 기간 Cafe24 판매 응답에 그 상품/옵션이 없는 경우

두 번째 경우는 Cafe24 판매 리포트가 “기간 내 판매 기록 없음”을 응답 누락으로 표현할 수 있기 때문에 업무적으로 판매수량 0으로 해석한다.

금지:

- API 실패/응답 중단을 `0`으로 표시
- 상품/옵션 존재 기준이 없는 응답 누락을 `0`으로 합산
- 기준표 보강값을 Cafe24 조회값처럼 표시

### 확인불가

상품/옵션 존재 기준을 확인할 수 없거나 API 실패/응답 중단 등으로 값을 신뢰할 수 없는 경우 화면에서는 좁은 셀 공간과 명확성을 함께 고려해 상태 표시를 사용한다.

- 좁은 숫자 셀: `미`
- 충분한 텍스트 영역 또는 상세 패널: `확인불가`
- tooltip/선택 상세: `상품/옵션 존재 기준을 확인할 수 없어 0으로 해석하지 않음.`

`-`는 일반적인 값 없음처럼 보일 수 있으므로, 숫자/금액처럼 업무 판단에 직접 영향을 주는 조회값에는 기본 표시로 쓰지 않는다.

### 기준표 보강값

상품명, 옵션명, 단가처럼 업무 기준표로 보강 가능한 값은 표시할 수 있다.

단, 사용자가 Cafe24 조회값으로 오해하지 않도록 상태를 보존한다.

- 화면 셀: 값은 그대로 표시
- tooltip/선택 상세: `기준표 값`
- Excel: 값과 함께 상태 `기준표`를 남긴다.

기준표 단가를 계산에 사용할지 여부는 기능별로 명시해야 한다. 명시 전에는 표시용 기준값으로만 취급한다.

## 계산 원칙

### 확인불가 값

확인불가 값은 절대 0으로 계산하지 않는다.

- 직접판매 수량 확인불가: 총판매/매출 계산에서 제외
- 단가 확인불가: 해당 매출 계산은 `missing` 또는 `partial`로 전파
- 매핑 수량 확인불가: 매핑 합계에서 제외하고 상태를 전파

### 합계와 소계

합계/소계는 값과 상태를 함께 표시한다.

| 입력 상태 | 합계 상태 | 화면 의미 |
|---|---|---|
| 모든 입력 조회됨 | `calculated` | 완전한 합계 |
| 일부 입력 확인불가 | `partial` | 확인불가 제외 합계 |
| 필수 입력 대부분 확인불가 | `missing` 또는 `partial` | 계산 불완전 |

화면에서는 좁은 셀 공간을 고려해 숫자 뒤에 `*`를 붙일 수 있다.

- 예: `37*`
- tooltip/선택 상세: `확인불가 항목 제외 합계`

Excel에서는 `*`만으로 끝내지 않고 상태/주석/범례로 의미를 보존한다.

## 화면 UX 규칙

1. 숫자 셀에서 `0`과 확인불가는 반드시 다르게 보여야 한다.
2. 확인불가 셀은 숫자가 아닌 상태 표시를 사용한다.
3. 확인불가 셀은 은은한 상태 스타일을 가진다.
   - 과한 경고색은 피한다.
   - 배경은 연회색 또는 연노랑 계열을 사용한다.
   - 텍스트는 숫자보다 낮은 대비이되 읽을 수 있어야 한다.
4. 기준표 보강값은 값 자체를 보여주되, 상세 정보에서 출처를 확인할 수 있어야 한다.
5. 합계/소계에 확인불가가 포함되면 숫자만 보여주지 않는다.
6. 선택 패널 또는 tooltip은 아래 정보를 제공한다.
   - 상태: 조회됨 / 기간 판매 없음 / 확인불가 / 기준표 / 확인불가 포함 계산
   - 출처: Cafe24 / 세트할인 구조설계 / 로컬 규칙 / 계산
   - 계산 포함 여부

## Excel 다운로드 규칙

Excel 다운로드는 화면과 같은 업무 맥락을 유지해야 한다.

### 값과 상태 분리

계산 안정성을 위해 Excel에서는 값과 상태를 분리한다.

- 숫자/금액 값 셀: 숫자 또는 빈값
- 상태 정보: 상태 컬럼, 주석, 범례 중 하나 이상으로 명시

확인불가 숫자값을 텍스트 `확인불가`로 숫자 셀에 직접 넣는 방식은 피한다. 후속 SUM, 피벗, 정렬, 복사 작업에서 혼선을 만들 수 있기 때문이다.

### Excel 표시 규칙

| 상태 | 값 셀 | 상태 표시 |
|---|---|---|
| Cafe24 조회값 0 | `0` | `조회됨` |
| Cafe24 조회값 있음 | 숫자 | `조회됨` |
| 기준표 존재 확인 + 기간 응답 없음 | `0` | `기간 판매 없음` |
| 확인불가 | 빈값 | `확인불가` |
| 기준표 보강값 | 값 | `기준표` |
| 확인불가 포함 합계 | 조회/기간 판매 없음 값의 합계 | `확인불가 제외 합계` |

### Excel 필수 보존 정보

Excel 파일에는 아래 중 하나 이상의 방식으로 상태 맥락을 남긴다.

- 상태 컬럼
- 셀 주석
- 범례 영역
- 합계 상태 셀

범례에는 최소한 아래 내용을 포함한다.

| 표시 | 의미 |
|---|---|
| `0` | Cafe24에서 조회된 실제 0 또는 존재 확인된 상품/옵션의 기간 판매 없음 |
| 빈값 + `확인불가` | 상품/옵션 존재 기준 또는 필수 값을 확인할 수 없음 |
| `기준표` | Cafe24가 아니라 기준표/로컬 정의로 보강한 값 |
| `확인불가 제외 합계` | 확인불가 항목을 제외하고 계산한 합계 |

## 상품코드 페이지 적용 메모

`상품코드` 페이지의 L상품 추가 작업에서는 아래 상황이 발생할 수 있다.

- `세트할인 구조설계` 탭에는 상품/옵션/단가가 존재하지만 Cafe24 기간 판매 응답에 일부 옵션이 없다.
- 이 경우 상품명/옵션명/단가는 기준표 값으로 표시할 수 있다.
- 기준표에서 상품/옵션 존재가 확인되면 직접판매 수량은 해당 기간 판매 없음으로 보고 `0`으로 표시/계산한다.
- 상품/옵션 존재 기준이 없거나 매칭이 불확실하면 직접판매, 총판매, 매출을 `0`으로 표시하거나 계산하면 안 된다.
- Cafe24 응답에 존재하고 수량이 실제 0이면 `0`으로 표시한다.
- 예:
  - `P00000TX F/G/H`가 Cafe24 응답에 있고 수량이 0이면 실제 `0`
  - `P00000TX B/C/D`가 기준표에 있고 Cafe24 기간 응답에 없으면 기간 판매 없음 `0`
  - `P00000VK C/D`가 기준표에 있고 Cafe24 기간 응답에 없으면 기간 판매 없음 `0`
  - `P00000VK M/N`이 Cafe24 응답에 있고 수량이 있으면 해당 수량 표시

## 수용 기준

구현 완료 판단은 아래를 모두 만족해야 한다.

1. Cafe24 조회값 0, 기간 판매 없음 0, 확인불가 값이 화면/Excel에서 업무적으로 구분된다.
2. Cafe24에서 읽어오는 모든 값이 상태/출처를 가진다.
3. 기준표 보강값은 Cafe24 조회값처럼 표시되지 않는다.
4. 확인불가는 0으로 계산되지 않는다.
5. 확인불가가 포함된 합계/소계는 전체 합계처럼 보이지 않는다.
6. Excel 다운로드에서 상태 맥락이 유지된다.
7. Excel 숫자 계산식은 텍스트 상태값 때문에 깨지지 않는다.
8. E2E는 최소한 아래 케이스를 검증한다.
   - Cafe24 조회값이 실제 0인 셀
   - 기준표에 존재하지만 Cafe24 기간 응답에 없는 기간 판매 없음 셀
   - 상품/옵션 존재 기준이 없는 확인불가 셀
   - 기준표 보강 상품명/옵션명/단가
   - 확인불가 포함 합계/소계
   - Excel 다운로드 후 상태 보존

## 미결정 사항

구현 전에 아래 사항은 별도 승인 또는 설계 결정이 필요하다.

1. 화면의 좁은 숫자 셀에서 확인불가를 `미`로 표시할지, 다른 표시를 쓸지
2. Excel에서 상태 컬럼을 실제 컬럼으로 추가할지, 주석/범례 중심으로 둘지
3. 기존 Excel 좌표계를 유지해야 하는 범위
4. 기준표 단가를 매출 계산에 사용할 수 있는 조건
5. 이 정책을 상품코드 페이지에 먼저 적용할지, 공통 데이터 모델로 확장할지
