# 엑셀 작성자 인터뷰 핵심 질문지

대상 시트: `상품코드_4월-NEW1`

참고 파일: [상품출고&순이익(2026)_NEW1_cafe24_1to1_checked_with_U_sales_v6.xlsx](./상품출고%26순이익%282026%29_NEW1_cafe24_1to1_checked_with_U_sales_v6.xlsx)

## 목적

엑셀 안에 숨어 있는 업무 규칙을 확인해서, 나중에 전산화할 수 있는 명확한 기준으로 바꾸는 것이 목적이다.

용어는 이렇게 정리했다.

- `L`: 최종적으로 판매수/원가/이익을 집계하고 싶은 기준 상품
- `U`: cafe24에서 별도 상품으로 팔렸지만, 내부 집계에서는 L로 옮겨야 하는 상품

## 가장 중요한 질문

### 1. 이 표의 최종 기준은 L 상품이 맞나요?

cafe24에서 어떤 상품코드로 팔렸든, 최종적으로는 왼쪽 L 상품 기준으로 몇 개 팔렸는지를 알고 싶은 것이 맞나요?

이게 맞아야 LU 매핑표를 만들 수 있습니다.

### 2. U 상품은 L 상품으로 어떻게 들어가야 하나요?

2026년 4월 하드왁스 범위는 cafe24와 대조해보니, `P00000YU`를 제외하면 대부분 이렇게 설명됩니다.

```text
U 옵션 판매수 = 특정 L 상품에 더할 수량
```

즉, 이 범위에서는 U 옵션 하나가 L 상품 하나로 1:1 대응된다고 봐도 될까요?

### 3. P00000YU / - 판매수 1은 어디에 넣어야 하나요?

cafe24에서 `P00000YU / -`가 1개 팔린 것으로 확인됩니다.

이 1개는 어느 L 상품에 반영해야 하나요?

아니면 현재 하드왁스 집계 범위에 포함하지 말아야 하나요?

### 4. 컵비즈는 1kg 합계에 포함되나요?

원본 엑셀에서는 `1kg총합계`의 수량 합계와 금액/원가 합계 범위가 서로 달라 보입니다.

정확히 확인하고 싶은 것은 이것입니다.

```text
컵비즈는 1kg 합계에 포함해야 하나요, 분리해야 하나요?
```

전산화할 때는 가능하면 아래처럼 명확히 나누고 싶습니다.

```text
컵비즈총합계
1kg총합계
컵비즈+1kg총합계
```

### 5. 박스/묶음 상품은 수량을 환산해야 하나요?

`1박스 18개`, `15EA`, `24개` 같은 상품은 cafe24 판매수 그대로 쓰면 안 되고, 실제 구성 수량만큼 곱해야 하나요?

예를 들어 `1박스 18개` 상품이 4개 팔리면 L 수량은 `4 × 18 = 72`로 보는 것이 맞나요?

### 6. L 상품 원가는 어디에서 가져와야 하나요?

cafe24에서는 판매가는 가져올 수 있지만 내부 원가는 가져올 수 없습니다.

L 상품별 원가는 어디에서 관리하나요?

원가는 월별로 바뀔 수 있나요?

## 인터뷰에서 꼭 결론내야 할 것

1. 최종 집계 기준이 L 상품인지
2. U 상품을 L 상품으로 옮기는 기준
3. `P00000YU / -` 판매수 1의 처리 방법
4. 컵비즈와 1kg 합계를 분리할지 포함할지
5. 박스/묶음 상품의 수량 환산 기준
6. L 상품별 원가 관리 기준

## 마지막 확인 질문

지금 엑셀에서 작성자만 알고 있는 예외 규칙이 더 있나요?

예를 들어 특정 상품은 수량을 곱해야 한다거나, 어떤 상품은 합계에서 빼야 한다거나, 특정 업체 판매분은 별도로 봐야 하는 규칙이 있는지 확인하고 싶습니다.
