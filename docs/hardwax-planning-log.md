# 하드왁스 LU셀 기획/개발 진행 기록

작성일: 2026-06-08

이 문서는 하드왁스 기능 관련 기획/결정사항을 작업 중에도 계속 이어서 기록한다.

> **LU셀 최상위 계약**  
> LU매핑은 `L 행 × U 열` 교차점에서 정의된 LU셀이다.  
> LU교차점에 LU매핑이 있으면 LU셀(확정)이다. (상세: [LU셀 계약](./lu-rule-contract.md))

## 1. LU/엑셀 용어 정합성

- `L`: 회사 기준 최종 집계 대상 상품(500g/1kg/비즈 하위 품목군)
- `U`: cafe24에서 별도 상품코드로 판매되는 항목(행사, 묶음, 세트, 키트 등)
- `LU매핑`: U 항목이 L로 반영되는 관계
- `LU셀`(새 용어): 엑셀 교차표에서 U 열과 L 행이 만나는 교차값(환산 수량).  
  - **최종 기준:** 해당 L행×U열 조합에 LU매핑이 있으면 LU셀이다.

## 2. LU셀이 표현하는 범위(현재 합의, “엑셀 시트 기반”)

- “현재 엑셀 시트(`상품코드_4월-NEW1`)에서 확인 가능한 범위”를 기준으로 판단한다.
- `LU셀`은 **LU매핑 존재 여부**로 판단한다.  
  - LU매핑 존재 + 계산값이 0이면 `0` 표시(매핑 확정된 LU셀)
  - LU매핑 미존재면 LU셀 아님. 화면에서는 `매핑 미정의` 셀로 표시.
- 최종 LU 매핑 확정은 회사와의 문의/합의 절차를 통해 별도로 확정한다.
- 운영 상 최종 룰(근본): LU 매핑은 회사 정책/문의 기반으로 확정.

## 3. BF 예외 규칙

- 현재 기준에서 `BF` 열(P00000YU, 라이콘 바디왁싱 스타터 키트20%할인)은 LU매핑이 정의되지 않은 상태로 처리한다.
- 즉 BF는 “예외” 처리한다.

## 12. 엑셀 재검증 결과 (2026-06-08)

- 검증 파일: `상품코드_4월-NEW1` 시트, `상품출고&순이익(2026)_NEW1_cafe24_1to1_checked_with_U_sales_v6.xlsx`
- 검증 방식: `U옵션판매수`(9행) + `RULES` 기준으로 UI 집계 규칙(현재 화면 구성: 코드 단위 L행) 재산출 후 비교.
- 1:1 규칙(현재 UI) 기준 차이 8건.

## 13. 상품코드/품목코드 계층 펼침 반영 (2026-06-08)

- 하드왁스 표에 `상품코드` 행 아래 `품목코드` 행을 접었다/펼쳤다.
- `상품코드` 행에 토글(▸/▾)을 배치해 개별 펼침·접힘 동작을 제공.
- 품목코드 행은 다음 값을 표시:
  - 코드: `variant_code` 접미사(품목코드)
  - 상품명: `option`
  - 단가: `fmtVariantPrice(option_price, catalog_price)`
  - 직접판매/매출: 품목 기준 수량/매출
- L상품의 LU교차값(열 값)은 상위 상품코드 행에 기존 방식 유지, 품목코드 행은 교차값 미반영(현재 데이터로 분해 불가)으로 0 처리로 유지.
- BF 열 예외 및 경계 규칙은 기존 정책 유지.

## 17. LU셀 배치 계산에서 인자 정합성 복구 (2026-06-08)

- `getRuleMatchQty`의 인자 시그니처 변경(변형 행렬 인덱스/다변종 여부 반영)에 맞춰
  상위행(상품코드) 집계와 하위행(품목코드) 집계에서 호출부 인자를 바로잡음.

  아래 힌트 좌표(`AM32`, `AN33`, `AO30`, `AP31`) 중심의 오차 재검증 대상으로 반영.
- BF 예외 정책은 기존대로 유지하고, 기존에 확인된 다른 오차 좌표와 함께 재검증 대상 목록에 반영.

## 18. 품목행 숨김 시 통합 표시 처리 (2026-06-08)

- 상품에 품목행이 있고 사용자 토글로 상품행이 `접힘` 상태인 경우:
  - 부모 행의 LU셀을 `부모값 + 숨긴 품목행 값`으로 집계해 표시.
  - 상태도 `mapped`/`unmapped`를 자식값 존재 기준으로 반영해 색상 의미 일치.
- 기대효과:
  - 사용자 요구대로 상품품목 코드를 숨길 때 `상품코드` 행에 통합 수치가 나타나며,
    예로 든 `P00000ZB`에서 접힌 상태의 LU셀 0-표시 이슈가 해소되는 흐름을 반영.

## 20. 상품품목코드 기준 표시 시 상품코드 행 셀 빈칸 처리 (2026-06-08)

- 다중 옵션 상품(품목코드 표시 상태: `상품코드` 행이 펼쳐진 상태)에서 상위 `상품코드` 행의 LU 매핑 셀은
`상품품목코드` 셀별 값과의 중복 표시를 피하기 위해 빈칸으로 렌더링하도록 변경.
- 표시 규칙:
  - 상품코드 행이 펼쳐진 상태(`품목코드` 행 노출): 상위 `상품코드` 행의 U열 LU값은 빈칸(`''`)으로 출력
  - 상품코드 행이 접힌 상태: 하위값 합산 결과를 기존대로 표시 (기존 병합 표시 규칙 유지)
- 0/미표시 구분을 위해 `0`이 아닌 빈칸 렌더링이 되도록 UI 표기만 수정

## 21. LU 매핑 정의 유무에 따른 표시 구분 (2026-06-08)

- LU셀은 정의된 매핑이면 `0`도 표시, 정의되지 않은 매핑이면 빈칸 표시로 정합화.
- 구현 변경:
  - `columnCellState()`가 값(`qty`)이 아닌 매핑 규칙 존재(`hasRule`) 기준으로 `mapped/unmapped` 판정.
  - 렌더링 시 `state === 'unmapped' && 값 === 0`은 빈칸(`''`) 처리.
  - `state === 'mapped'`는 값이 `0`이더라도 `0`을 표시해, LU매핑 정의 셀과 미정의 셀을 구분.

## 22. LU셀 `0` 표기 규칙의 최종 확정 (2026-06-08)

- 최종 규칙(화면 렌더링):
  - **1)** LU매핑 규칙이 존재하고 해당 셀 계산값이 `0`이면 반드시 `0` 표시.
  - **2)** LU매핑 규칙이 없으면 값이 `0`이더라도 반드시 빈칸.
  - **3)** 즉, `0`은 항상 "매핑 정의가 확인된 후 계산된 값"일 때만 유효.
- 반영 효과:
  - 매핑 미정의 셀에서의 오해(0 vs 공란) 제거
  - 매핑 정의 셀에서의 값 부재를 `0`으로 정확히 구분

  - `th/td` 패딩 축소(`4px 5px` → `2px 3px`)
  - 고정열(`코드/상품명/단가/직접판매`) 최소 폭 축소
  - U변형 열(`.matrix-variant`) 폭을 `44px`에서 `32px`로 축소
  - 블록 헤더(`.u-header`) 최소/최대 폭 축소
- 목표: 엑셀형 긴 행렬에서 과도한 컬럼 폭을 낮추고 좌우 스크롤 폭 부담 완화

## 24. LU셀 지정/해제 Phase B 최소 구현 정합 (2026-06-09)

- 요구 반영: 화면에서 LU셀은 값 여부가 아닌 **지정 상태** 기준으로 판단.
- 구현 원칙:
  - 기준은 `baseRules(RULES)` + `userOverrides`로 계산한 `effectiveRules`.
  - baseRules는 읽기 전용으로 유지하고, 사용자 액션은 `luOverrides`(add/remove)만 저장/적용.
  - 셀 상태 분기:
    - `lu-defined`: `effectiveRules`에 해당 L×U 매핑이 존재 (`값이 0이어도 0 표시`)
    - `candidate`: 값은 있으나 매핑 미지정인 검토 대상. Phase B에서는 숫자 표시/합계/수식 포함 금지.
    - `empty`: 값 없고 미지정. 공란 표시.
    - `excluded`: BF 예외 등 기존 제외 정책 유지
- 사용자 액션:
  - 더블클릭:
    - LU 미지정 셀(빈칸/후보)을 클릭하면 `lu-defined`로 설정(빈칸이라도 0 표시).
    - LU 지정 셀을 클릭하면 해제(기본 규칙이면 remove override 추가).
  - 1:1 제약:
    - 동일 U 열의 기존 매핑이 있으면 새 지정 시 이전 매핑 이동/대체 처리(오버라이드로 이전 매핑 비활성화 후 신규 매핑 추가).
- 범위 제한:
  - Phase B에서는 더블클릭 지정/해제만 구현한다.
  - 상/하 이동 및 서버/브라우저 영구 저장은 후속 Phase로 분리한다.

## 25. 매핑셀 사용자 용어 및 더블클릭 확인 UX 기획 (2026-06-09)

- 용어 결정:
  - `LU셀`은 개발/기획 내부 용어로 유지한다.
  - 사용자 화면에서는 `LU셀` 대신 `매핑셀`을 사용한다.
  - `매핑셀`은 “U상품 판매를 L상품 집계에 반영하는 교차셀”이라는 의미로 설명한다.
- 더블클릭 UX 원칙:
  - 더블클릭 즉시 반영하지 않고, 확인 모달을 거친 뒤 반영하는 방향이 안전하다.
  - 확인 문구는 셀의 현재 상태와 작업 영향을 구분해서 보여준다.
  - 모달에는 대상 U상품/옵션, 대상 L상품/옵션, 반영 수량, 단가/매출 영향(확인 가능한 경우), 총판매/매출/수식 변경 여부를 표시한다.
- 빈 미지정 셀 더블클릭:
  - 제목 예: `이 교차셀을 매핑셀로 지정할까요?`
  - 설명: `지정하면 수량 0인 매핑셀로 표시되고, 수량이 0이어도 총판매/매출 수식 항에 포함됩니다.`
  - 버튼: `매핑셀로 지정`, `취소`
- 값이 있는 미지정/검토 대상 셀 더블클릭:
  - 제목 예: `이 U상품 판매를 L상품 집계에 반영할까요?`
  - 설명: `지정하면 해당 U상품 판매가 선택한 L상품의 총판매, 매출, 수식에 포함됩니다.`
  - 버튼: `매핑셀로 지정`, `취소`
  - 주의: 검토 대상 셀은 숫자를 LU교차표에 반복 표시하지 않는다. 필요한 수량 정보는 확인 모달 안에서만 보조 정보로 보여준다.
- 기존 기본 매핑셀 더블클릭:
  - 제목 예: `기본 매핑셀을 해제할까요?`
  - 설명: `기본 규칙을 삭제하지 않고 사용자 변경사항으로만 비활성화합니다. 해제하면 이 U항은 총판매/매출/수식에서 제외됩니다.`
  - 버튼: `매핑셀 해제`, `취소`
- 사용자 지정 매핑셀 더블클릭:
  - 제목 예: `사용자 지정 매핑셀을 취소할까요?`
  - 설명: `이 셀은 미지정 상태로 돌아가며, 총판매/매출/수식에서 제외됩니다.`
  - 버튼: `지정 취소`, `취소`
- 같은 U열이 이미 다른 L행에 매핑된 상태에서 새 L행을 지정하는 경우:
  - 제목 예: `이 U상품의 매핑 대상을 변경할까요?`
  - 설명: `현재 매핑 대상과 변경 후 대상을 함께 표시하고, 변경하면 기존 매핑셀은 해제되고 새 셀만 매핑셀로 지정됩니다.`
  - 버튼: `변경`, `취소`
- 구현 상태:
  - `Phase B-Confirm`으로 더블클릭 확인 모달을 적용한다.
  - `pendingLuAction` 상태에 더블클릭 요청을 저장하고, 확인 버튼에서만 기존 `toggleLuCell()`을 실행한다.
  - 상/하 이동은 계속 후속 Phase로 유지한다.

## 26. 하드왁스 화면 CSS 원칙: `!important` 금지 (2026-06-10)

- 원칙:
  - 하드왁스 화면 CSS에서는 `!important`를 사용하지 않는다.
  - 선택 강조, sticky, hover, 상태 표시가 충돌하더라도 `!important`로 덮지 않는다.
- 이유:
  - `!important`는 상태별 우선순위를 불투명하게 만들어 후속 수정에서 예측 가능성을 떨어뜨린다.
  - LU/매핑셀, 미지정 교차셀, 선택 행/열/셀, sticky header처럼 상태가 많은 화면에서는 우선순위가 명시적으로 관리되어야 한다.
- 대체 방식:
  - selector specificity를 의도적으로 높인다.
  - 상태 class를 분리한다.
  - DOM 구조나 CSS 계층을 정리해 충돌 원인을 제거한다.
  - 공통 규칙보다 화면 전용 규칙을 뒤에 배치한다.
- 완료 기준:
  - `rg -n "!important" frontend/src/pages/ExcelOrderView.css frontend/src/pages/ExcelOrderView.tsx` 결과가 없어야 한다.

## 27. U상품 컬럼의 전환상품과 세트 상품 구분 (2026-06-22)

- 하드왁스 화면의 U상품 컬럼을 업무 성격에 따라 시각적으로 구분한다.
- 용어:
  - 세트 상품: 여러 구성품을 하나의 판매상품으로 묶어 판매하는 U상품
  - 전환상품: 세트 상품이 아닌 U상품. Cafe24에서는 별도 판매상품이지만 내부 집계에서는 특정 L상품/품목으로 전환 집계되는 상품
- 세트 상품으로 구분한 컬럼:
  - `P00000YZ`
  - `P00000YS`
  - `P00000YU`
  - `P00000VP`
  - `P00000VA`
- 표시 규칙:
  - 전환상품 컬럼을 먼저 표시한다.
  - 세트 상품 컬럼은 오른쪽에 모아 표시한다.
  - 세트 상품 컬럼은 별도 헤더 색상, 연한 컬럼 배경, 그룹 시작 구분선으로 식별한다.
  - `P00000VP`, `P00000VA`는 세트 상품 조회/표시 대상에 포함한다.
