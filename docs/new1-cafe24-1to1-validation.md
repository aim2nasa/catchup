# 상품코드_4월-NEW1 cafe24 1:1 검증 결과

## 대상

- 원본 검토 파일: [상품출고&순이익(2026)_NEW1.xlsx](./상품출고%26순이익%282026%29_NEW1.xlsx)
- 검증 반영 파일: [상품출고&순이익(2026)_NEW1_cafe24_1to1_checked_with_U_sales_v6.xlsx](./상품출고%26순이익%282026%29_NEW1_cafe24_1to1_checked_with_U_sales_v6.xlsx)
- 대상 시트: `상품코드_4월-NEW1`
- 대상 기간: 2026-04-01 ~ 2026-04-30
- 검증 기준: cafe24 연동 조회 결과

## 검증 가정

이번 검증은 `LU 매핑이 1:1`이라는 가정으로 수행했다.

즉, U 상품품목코드 하나가 특정 L 상품품목코드 하나로 대응되고, 별도 환산 배수를 적용하지 않는다고 보았다.

```text
U 옵션 판매수 = 해당 L 행에 반영되는 수량
```

단, 이 결론은 이번 `상품코드_4월-NEW1` 검증 범위에 한정한다. 전체 업무 규칙이 항상 1:1이라는 의미는 아니다.

## 검증 방식

1. `상품코드_4월-NEW1`의 U 헤더 상품코드/상품품목코드를 읽었다.
2. cafe24 연동 API로 2026년 4월 각 U 옵션의 판매수를 조회했다.
3. 엑셀의 U열별 L 배치 합계와 cafe24 옵션별 판매수를 비교했다.
4. D열 직접판매 수량도 cafe24 L 상품품목 판매수와 비교했다.
5. 검증 편의를 위해 8행과 기존 9행 사이에 `U옵션 판매수` 행을 추가했다.
6. 기존 수식, 병합 구조, 외부 링크 여부를 재검증했다.

## 최종 결과

`P00000YU / -`를 제외하면, 이번 검증 범위의 U-L 관계는 1:1 매핑으로 설명된다.

확인된 사항:

- U옵션 판매수 행 `9행`은 cafe24 옵션별 판매수와 일치한다.
- D열 직접판매 수량은 cafe24 L 상품품목 판매수와 일치한다.
- U열별 L 배치 합계는 cafe24 U 옵션 판매수와 일치한다.
- cafe24에 판매된 양수 U 옵션 중 엑셀에 누락된 품목은 없다.
- L/U 상품품목코드 존재 여부에 문제 없다.
- 행/열 합계 수식은 정상이다.
- 병합 구조는 원본 `상품코드_4월-NEW1` 구조와 맞게 유지했다.
- 외부 링크는 제거되어 있으며, v6 파일은 Excel COM으로 열림을 확인했다.

## 남은 예외

### P00000YU / -

- 상품코드: `P00000YU`
- 표시 품목코드: `-`
- cafe24 판매수: `1`
- v6 파일 표시 위치: `BF9`
- 상태: L 행 배치 미확정

이 값은 cafe24에서는 판매수 1이 확인되지만, 현재 500g/컵비즈/1kg L 행 중 어느 상품으로 환산해야 하는지 확정하지 못했다.

따라서 `BF9`에는 U 옵션 판매수로 표시했지만, L 행 수량에는 반영하지 않았다.

작성자 인터뷰 질문:

- `P00000YU / -`의 판매수 1은 어떤 L 상품에 반영해야 하는가?
- 이 상품은 현재 하드왁스 500g/컵비즈/1kg 집계 범위에 포함되는 상품인가?
- 포함되지 않는다면 별도 집계 구간으로 분리해야 하는가?

## 수정 반영 요약

v6 파일에는 cafe24 1:1 검증 결과를 반영했다.

주요 수정:

| 항목 | 수정 내용 |
|---|---|
| `P00000QD / CM` | 맨니피코하드 104를 올바른 옵션 열로 이동 |
| `P0000BLA / P` | cafe24 판매수 1을 `P0000BIF / CO` 행에 반영 |
| `P00000VM` | 1kg 묶음할인 옵션의 여러 값이 실제 옵션코드에 맞도록 재배치 |
| `P00000YU / -` | 판매수 1은 `BF9`에 표시, L 행 배치는 미확정 처리 |

## 파일 사용 기준

- `v6` 파일을 현재 검증본으로 사용한다.
- 이전 `v2`, `v3`, `v4`, `v5` 파일은 사용하지 않는다.
- `변경내역` 탭은 보조 시트였으므로 삭제해도 계산에는 영향 없다.
- 최종 업무 확정 전에는 `P00000YU / -`의 L 매핑을 작성자에게 확인해야 한다.
