P00000YU는 L에 있는게 적절해? 아니면 U에 있는게 적절해?

## Assistant

`P00000YU` 자체는 **U에 있는 게 적절합니다.**

이유는 `P00000YU`가 Cafe24의 판매 상품 코드이고, 옵션도 `P00000YU000B / 도매=묶음`인 **키트 판매 단위**이기 때문입니다. 즉 주문/판매수 집계의 원천 U로 두는 게 맞습니다.

반면 L에는 `P00000YU`를 그대로 두기보다, 출고/재고 차감 관점에서 키트 구성품으로 **분해된 실제 상품**이 들어가는 게 맞습니다. 이 키트의 하드왁스 구성품만 L에 반영한다면 `P00000CH / 로즈퓨어하드`가 가장 적절합니다.

정리하면:

- U: `P00000YU / 라이콘 바디왁싱 스타터 키트20%할인`
- L: 키트 구성품들
- 하드왁스 L 후보: `P00000CH / 로즈퓨어하드`
- 전체 키트 분해 시: 로즈퓨어하드, 바닐라 스트립왁스, 미니전후처리제, 인그로운 125ml, 부직포, 워머기, 스파츌러류 등

따라서 지금 엑셀 구조가 “U 판매상품 → L 출고상품” 매핑이라면 `P00000YU`는 U에 두고, L에는 구성품을 연결하는 방식이 맞습니다.

## Assistant

맞습니다. 지금 구조에서는 그게 핵심 문제입니다.

`P00000YU`는 키트라서 `P00000CH` 하나로 매핑하면 **부분 매핑**일 뿐입니다. Cafe24 상세 기준 구성은 대략:

- A: `P00000CH` 로즈퓨어 핫왁스 1Kg
- B: `P00000CM` 바닐라 스트립왁스 800ml
- C: `P00000WO` 미니전후처리제5종세트125ml
- D: `P00000BJ` 인그로운 X-IT 솔루션 125ml
- E: `P00000DD` 라이콘 스트립 부직포 250매
- F: 워머기 2구 1000/1000
- G: 메탈/바디/페이셜 스파츌러류

현재 `상품코드_4월-NEW1`의 L 범위가 하드왁스 중심이라면, 그 안에는 A만 있고 B/C/D/E/F/G는 빠져 있는 상태로 보는 게 맞습니다.

그래서 선택지는 둘 중 하나입니다.

1. **하드왁스 시트에서는 `P00000YU`를 미반영/확인 필요로 둔다**
   - 가장 보수적입니다.
   - `P00000CH`에 1개를 넣으면 키트 전체 출고를 하드왁스 1개로 축소해버리는 오해가 생깁니다.

2. **키트 분해 매핑 테이블을 별도로 만든다**
   - `P00000YU x 1 → P00000CH x 1 + P00000CM x 1 + P00000WO x 1 + ...`
   - 이후 L 범위에 존재하는 구성품만 해당 시트에 반영하고, 빠진 구성품은 “현재 L 범위 외”로 표시합니다.

제가 보기엔 지금 엑셀에서는 **`P00000YU`를 `P00000CH` 단독으로 확정 매핑하면 안 됩니다.**  
정확한 표현은 “`P00000YU` 키트 구성품 중 하드왁스 항목은 `P00000CH`로 보이나, 전체 L 매핑은 불완전”입니다.

실무적으로는 두 선택지 중 **`P00000YU`의 L 매핑을 완성하는 쪽**이 더 맞아 보입니다.

이유:
- `P00000YU`는 Cafe24에서 판매되는 **U 상품**입니다.
- 실제 출고/재고 차감은 키트 구성품 단위로 일어나야 합니다.
- 이미 구성품이 Cafe24 등록 상품으로 존재합니다.
- `P00000YU`를 L 상품으로도 정의하면 “판매 키트”와 “출고 실물”이 같은 코드가 되어, 나중에 재고/원가/구성품 분석에서 의미가 섞입니다.

따라서 권장 구조는:

```text
U: P00000YU / 라이콘 바디왁싱 스타터 키트20%할인
L:
  P00000CH / 로즈퓨어하드
  P00000CM / 라이코플렉스 바닐라 스트립왁스 800ml
  P00000WO / 미니전후처리제5종세트125ml
  P00000BJ / 인그로운 X-IT 솔루션 125ml
  P00000DD / 라이콘 스트립 부직포 250매
  워머기 2구 1000/1000
  메탈 스파츌러
  바디 스파츌러
  페이셜 스파츌러
```

단, 워머기/스파츌러류는 현재 단품 코드와 묶음 옵션 코드가 여러 개라서 “어떤 L 코드 체계를 쓸지”를 정해야 합니다. 예를 들면 단품 기준이면 `P00000DH` 같은 개별 스파츌러 코드, 옵션 묶음 기준이면 `P00000WL`/`P00000SA` 계열을 쓸 수 있습니다.

반대로 `P00000YU`를 L 상품으로 정의하는 방식은 이런 경우에만 괜찮습니다:

```text
L: P00000YU / 라이콘 바디왁싱 스타터 키트
```

그리고 하위 구성품 재고는 추적하지 않는다.

즉 출고 관리를 “키트 박스 단위”로만 한다면 가능하지만, 지금처럼 하드왁스/스트립/소모품까지 L로 관리하려는 흐름이라면 부적합합니다.

제 판단은: **`P00000YU`는 U로 유지하고, L 매핑을 완성하는 게 맞습니다.**
