# P00000YU L 매핑 문의 요약

## 핵심 질문

`P00000YU / 라이콘 바디왁싱 스타터 키트20%할인`을 현재 매핑 구조에서 어떻게 처리해야 하는지 확인이 필요하다.

선택지는 크게 두 가지다.

1. `P00000YU`를 U 상품으로 유지하고, L에는 키트 구성품을 모두 분해 매핑한다.
2. `P00000YU` 자체를 L 상품으로 정의해 키트 단위로 출고 처리한다.

현재처럼 `P00000YU`를 U에는 두되 L 매핑은 일부만 하거나 미확정으로 두면 계속 예외 상태로 남는다.

## Cafe24 확인 결과

Cafe24 등록 상품 전체 687개를 조회했다.

`P00000YU` 정보:

- 상품번호: `644`
- 상품명: `라이콘 바디왁싱 스타터 키트20%할인`
- 품목코드: `P00000YU000B`
- 옵션: `도매 = 묶음`
- 판매 단위: 키트 묶음 상품

상세 이미지 기준 구성품:

- 라이콘 2구 왁스워머기 `(1000/1000)`
- 하드왁스 1Kg `(로제트)`
- 스트립왁스 800ml `(바닐라)`
- 미니 전후처리제 5종 125ml
- 인그로운 스프레이 125ml
- 부직포 250매
- 메탈 스파츌러
- 바디 스파츌러
- 페이셜 스파츌러

## 현재 문제

현재 하드왁스 중심 L 범위에는 `P00000CH`만 들어 있고, 나머지 구성품은 빠져 있는 상태로 보인다.

따라서 `P00000YU`를 `P00000CH` 하나로만 매핑하면 키트 전체를 하드왁스 1개로 축소해버리는 부분 매핑이 된다.

## 권장안

운영 목적이 구성품별 출고/재고/원가 관리라면:

```text
P00000YU는 U 상품으로 유지하고,
L에는 키트 구성품을 모두 분해 매핑한다.
```

운영 목적이 키트 박스 단위 출고만 관리하는 것이라면:

```text
P00000YU 자체를 L 상품으로 정의한다.
```

4. 현재 하드왁스 시트에는 `P00000CH`만 반영하고 나머지는 별도 L 범위에서 관리할 것인가?
