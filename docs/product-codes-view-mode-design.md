# 상품코드 페이지 보기 모드 UX 설계안

## 목적

좁은 모니터에서도 `상품코드` 페이지의 U상품 교차 매트릭스를 더 많이 한 번에 볼 수 있게 한다.

이 문서는 `상품코드~직접판매` 왼쪽 정보 영역을 사용자가 작업 목적에 맞게 접거나 펼치는 UX를 정의한다. 핵심은 컬럼 숨김 기능 자체가 아니라, 사용자가 원하는 방식으로 표를 쉽게 읽고 비교할 수 있게 하는 것이다.

## 참조 요구사항

- 요구사항 인박스: `REQ-20260624-02: 상품코드 페이지 보기 모드로 좁은 화면 UX를 개선한다`

## 사용자 문제

`상품코드` 페이지는 아래 두 정보를 동시에 보여준다.

- 왼쪽 L상품 정보: 상품코드, 상품명, 코드, 옵션명, 단가, 직접판매
- 오른쪽 U상품 교차 매트릭스: U상품별 판매/매핑 수량

좁은 화면에서는 왼쪽 고정 영역이 많은 폭을 차지해 U상품 컬럼이 적게 보인다. 사용자는 U상품 값을 비교하기 위해 수평 스크롤을 반복해야 한다.

반대로 왼쪽 정보를 완전히 숨기면 현재 행이 어떤 L상품/옵션인지 잃을 수 있다. 따라서 단순히 컬럼을 제거하는 것이 아니라, 작업 목적별로 정보 밀도를 조절해야 한다.

## UX 목표

1. 좁은 화면에서도 U상품 컬럼을 더 많이 볼 수 있어야 한다.
2. 사용자는 현재 행의 L상품 식별 맥락을 잃지 않아야 한다.
3. 보기 전환은 빠르고 예측 가능해야 한다.
4. 사용자가 숨긴 컬럼을 기억하거나 추측하게 만들지 않아야 한다.
5. Excel 좌표계, 셀 선택, 다운로드 맥락은 깨지지 않아야 한다.

## 비목표

1차 구현에서는 아래를 하지 않는다.

- Excel 다운로드 컬럼을 화면 숨김 상태와 동일하게 변경
- 모든 컬럼의 드래그 리사이즈
- 사용자별 서버 저장 설정
- 하드왁스 페이지 공통화
- 행/열 피벗 재설계

## 설계 원칙

### 보기 모드가 우선이다

처음부터 컬럼별 체크박스만 제공하면 사용자는 매번 어떤 컬럼을 숨길지 결정해야 한다. 이는 자유도는 높지만 사용 부담도 크다.

따라서 1차는 작업 목적별 보기 모드로 제공한다.

- 상세
- 넓게
- 초점

컬럼별 사용자 지정은 2차 기능으로 분리한다.

### 화면 표시만 조절한다

Excel 좌표계와 다운로드 안정성을 위해 1차 구현은 화면 표시만 조절한다.

- 내부 컬럼 키는 유지한다.
- Excel 다운로드는 전체 정보를 유지한다.
- `data-a1`, 셀 선택, 수식 표시, 복사 동작은 기존 구조를 유지한다.
- 숨김 컬럼은 DOM 제거보다 폭 축소 또는 화면 표시 숨김을 우선 검토한다.

### 숨겨도 맥락을 보완한다

왼쪽 정보 일부가 숨겨질 때는 선택 셀 정보, hover/title, 상단 선택 패널 등으로 행 맥락을 확인할 수 있어야 한다.

## 보기 모드

### 상세

현재 기본 정보 확인 모드다.

표시:

- 상품코드
- 상품명
- 코드
- 옵션명
- 단가
- 직접판매

사용 상황:

- 상품/옵션 검수
- 단가 확인
- 직접판매 수량 확인
- 데이터 검증

기본값:

- 넓은 화면에서는 `상세`를 기본값으로 둔다.

### 넓게

U상품 매트릭스를 더 많이 보기 위한 균형 모드다.

표시:

- 상품코드
- 상품명은 좁게 표시
- 코드
- 옵션명은 좁게 표시
- 직접판매

축소 또는 숨김 후보:

- 단가: 숨김 또는 최소 폭
- 상품명/옵션명: compact 폭 유지, 한 줄 말줄임

사용 상황:

- U상품별 교차셀 비교
- 매핑 위치 확인
- 좁은 모니터에서 일반 분석

기본값:

- 좁은 화면에서는 `넓게`를 기본값 후보로 둘 수 있다.
- 단, 자동 전환은 사용자가 예상하지 못할 수 있으므로 1차에서는 수동 전환을 우선한다.

### 초점

U상품 매트릭스 분석을 최우선으로 하는 모드다.

표시:

- 상품코드
- 코드
- 직접판매

숨김:

- 상품명
- 옵션명
- 단가

맥락 보완:

- 행 hover 또는 선택 시 상품명/옵션명/단가를 상단 선택 정보에 표시한다.
- 셀 선택 패널에는 숨겨진 L상품 정보가 포함되어야 한다.
- 필요 시 row title로 전체 상품명/옵션명을 확인할 수 있어야 한다.

사용 상황:

- U상품 교차셀 숫자 탐색
- 특정 U상품 구간 비교
- 좁은 모니터에서 빠른 매핑 검토

## 후속 기능: 사용자 지정

보기 모드가 충분하지 않으면 2차로 컬럼별 사용자 지정을 제공한다.

대상 컬럼:

- 상품코드
- 상품명
- 코드
- 옵션명
- 단가
- 직접판매

권장 UI:

- `보기` 메뉴 안에 `컬럼 표시` 섹션 제공
- 체크박스 방식
- `기본값으로 복원` 제공
- localStorage로 브라우저별 상태 저장

주의:

- 상품코드와 코드를 동시에 숨기면 행 식별이 어려워진다.
- 모든 식별 컬럼을 숨기는 조합은 막거나 경고해야 한다.
- 총판매/매출 고정 영역과 충돌하지 않아야 한다.

## UI 배치

권장 위치:

- 날짜 필터, Excel 다운로드, 조회 버튼과 같은 줄 또는 표 상단 보조 영역
- 라벨: `보기`
- 형태: 세그먼트 컨트롤 또는 작은 메뉴

1차 권장:

```text
보기  [상세] [넓게] [초점]
```

상태 저장:

- 1차: localStorage 저장 권장
- 저장 키 예: `product-codes:view-mode`
- 저장 범위: 브라우저별

## 데이터 및 Excel 영향

### 화면

보기 모드는 화면 표시 폭과 표시 여부만 바꾼다.

### Excel 다운로드

1차 구현에서는 Excel 다운로드에 보기 모드를 반영하지 않는다.

이유:

- 사용자가 화면에서 임시로 숨긴 컬럼이 Excel에서 사라지면 데이터 누락으로 오해할 수 있다.
- Excel 파일은 독립 문서로 열리므로 전체 맥락을 유지하는 편이 안전하다.

후속 검토:

- `현재 보기대로 다운로드` 옵션을 별도 기능으로 둘 수 있다.

### 셀 선택/복사

숨긴 컬럼이라도 내부 좌표계와 데이터는 유지한다.

- 셀 주소 표시 유지
- 선택 셀 정보 유지
- 수식/복사 동작 유지
- 숨김 컬럼의 정보는 선택 상세에서 볼 수 있게 한다.

## 접근성 및 가독성

- 보기 모드 버튼은 현재 선택 상태를 명확히 보여야 한다.
- 숨김 상태는 표 안에 과한 배지를 만들지 않는다.
- 숨겨진 정보는 hover/title 또는 선택 정보로 확인 가능해야 한다.
- 텍스트 말줄임은 title 또는 선택 상세로 보완한다.

## E2E 검증 기준

필수 케이스:

1. 상세 보기에서 기존 컬럼이 모두 보인다.
2. 넓게 보기에서 U상품 컬럼 가시 영역이 상세 보기보다 넓어진다.
3. 초점 보기에서 상품명/옵션명/단가가 숨겨지고 U상품 영역이 더 넓어진다.
4. 초점 보기에서도 행 선택 시 숨겨진 상품명/옵션명/단가를 확인할 수 있다.
5. 보기 모드 전환 후 수평 스크롤이 비정상적으로 튀지 않는다.
6. 보기 모드 전환 후 행 높이가 예기치 않게 바뀌지 않는다.
7. Excel 다운로드는 전체 컬럼 정보를 유지한다.
8. 새로고침 후 저장된 보기 모드가 복원된다. 저장을 1차 범위에서 제외하면 복원되지 않는 것이 정상임을 검증한다.

## 구현 배치 제안

### 1차 배치: 보기 모드

- `상세`, `넓게`, `초점` 모드 추가
- 화면 표시만 조절
- 선택 정보에 숨김 컬럼 맥락 보완
- E2E 추가

### 2차 배치: 컬럼별 사용자 지정

- `보기` 메뉴 안에 컬럼 체크박스 추가
- 식별 불가능 조합 방지
- localStorage 저장

### 3차 배치: 다운로드 옵션

- 전체 다운로드
- 현재 보기대로 다운로드

## 미결정 사항

1. 1차에서 localStorage 저장을 포함할지
2. 좁은 화면에서 기본 모드를 자동으로 `넓게`로 바꿀지
3. `넓게` 모드에서 단가를 완전히 숨길지, 최소 폭으로 둘지
4. `초점` 모드에서 상품코드를 남길지, 코드+직접판매만 남길지
5. 숨김 컬럼 정보를 상단 선택 패널에 어느 정도까지 보여줄지

## 권장 결정

1차 구현은 아래로 진행하는 것이 가장 안전하다.

- 보기 모드: `상세`, `넓게`, `초점`
- 기본값: `상세`
- 저장: localStorage 포함
- Excel 다운로드: 전체 컬럼 유지
- `넓게`: 단가 숨김, 상품명/옵션명 compact
- `초점`: 상품코드, 코드, 직접판매만 표시
- 숨김 정보: 선택 셀 정보 영역에서 상품명/옵션명/단가 표시

이 방식은 좁은 화면에서 U상품을 더 많이 보려는 목표를 만족하면서도, 사용자가 행의 업무 맥락을 잃지 않게 한다.
